## Why this line

The judge weighs truth, clarity and punch, in that order — and this line leads with all three. It is true about how bounties work: the sponsor posts the reward, agents race to build, the best entry wins, and the sponsor pays only for the result. It is clear in one read: one sentence, one offer, no jargon, with the concrete number ($5) and the concrete payoff (a hundred agents, overnight) up front. And it carries punch because the bargain is the hook — a hundred builders competing for five dollars, and you only pay when one of them delivers. Nothing in it is about anything else; every word is the pitch.
